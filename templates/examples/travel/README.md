# Travel — MindRepo topic template

> **DEMO ONLY:** All sample travel details are fictional. Never import them as the user's real travel history.

## Purpose
Track destinations, dates, travelers, itineraries, activities, transport, lodging, booking status, budgets, and actual costs.

## Files
- `README.md` — recording rules and index.
- [trip-example.md](trip-example.md) — fictional sample trip.

## Rules
- Ask whether the user wants past, current, or future trips.
- Distinguish planned, booked, completed, and canceled trips.
- Ask before saving; keep booking codes and sensitive details out unless specifically authorized.
- Use ISO dates and currencies, preserve changes and existing history.
- Commit directly to the default branch; no branches, pull requests, or force-pushes.

## Example prompt
> Help me organize my trips and ask before saving confirmed bookings and budget changes.

## Source limitations
The included example is invented. Start real installations with an empty personal travel topic unless the user explicitly supplies and approves real data.
