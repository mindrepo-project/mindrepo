# Contributing to MindRepo

Thanks for helping make MindRepo better!

MindRepo is a lightweight, topic-organised knowledgebase stored in a private GitHub repository and managed through an AI assistant. Contributions should keep the setup understandable, privacy-conscious, and provider-agnostic where possible.

## Ways to contribute

- Report installation problems using a [bug report](../../issues/new/choose).
- Suggest improvements using a [feature request](../../issues/new/choose).
- Ask questions and share ideas in [Discussions](../../discussions).
- Improve documentation, examples, and accessibility.

## Before contributing

1. Check existing issues and discussions to avoid duplicates.
2. For substantial changes, open an issue or discussion first.
3. Keep pull requests focused and explain the user-facing benefit.
4. Test documentation and setup instructions against a **test repository**, never a repository containing personal information.

## Privacy and safety

**Never include real personal knowledgebase content**, private repository contents, access tokens, credentials, or other sensitive information in issues, discussions, pull requests, screenshots, or examples. Use fictional data.

Example topics are inspiration only. The installation assistant must not copy example file structures, names, or rules into a user's repository unless the user explicitly requests them.

Any repository write must require clear user approval. Do not describe MindRepo as an automatic background sync service.

## Pull requests

- Describe what changed and why.
- Include reproduction steps for fixes or before/after behaviour for enhancements.
- Update relevant documentation when behaviour changes.
- Respect the existing MIT licence.

For sensitive security reports, follow [SECURITY.md](SECURITY.md) rather than opening a public issue.
