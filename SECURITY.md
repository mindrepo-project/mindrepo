# Security Policy

MindRepo is a set of prompts and repository templates. Your knowledgebase is stored in a GitHub repository you control.

## Reporting a vulnerability

**Do not disclose vulnerabilities, credentials, private repository data, or other sensitive information in public issues or discussions.**

If GitHub's private vulnerability reporting is enabled for this repository, use **Security → Report a vulnerability** to report a security issue privately.

If private reporting is not available, open a public issue containing **no sensitive details** to request a secure contact method. Do not include exploit details or personal information.

## Security expectations

- Keep personal knowledgebases in **private repositories**.
- Grant integrations only the permissions they need.
- Review and approve proposed changes before they are committed.
- Never paste access tokens or secrets into prompts, issues, or example files.
- Use fictional data in public examples and bug reports.

No formal security response time or support guarantee is offered.
